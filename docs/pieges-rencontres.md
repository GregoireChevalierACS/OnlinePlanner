# Pièges rencontrés

| Symptôme | Cause | Contournement | Lien |
| --- | --- | --- | --- |
| Alerte GitGuardian « Generic High Entropy Secret » sur `backend/.env.dev` | La recette Flex de `symfony/framework-bundle` génère un `APP_SECRET` réel dans `.env.dev`, fichier versionné | Ne jamais versionner `APP_SECRET` : le définir dans `backend/.env.dev.local` (ignoré). Relire tout `.env*` avant `git add`. Secret scanning + push protection activés sur GitHub | commit `2026-11-13 # 1` |
| Infection échoue : « Could not validate the PHPUnit configuration file … exceeded the timeout of 2 seconds » | Volume Docker monté depuis Windows trop lent | Copier le code dans le conteneur avant de lancer : `docker run --rm -v "$(pwd -W):/src:ro" onlineplanner-api sh -c "cp -r /src /work && cd /work && vendor/bin/infection"` | — |
| Commandes Docker en Git Bash : chemins réécrits (`/app` → `C:/Program Files/Git/app`) | Conversion automatique de chemins MSYS | Préfixer par `MSYS_NO_PATHCONV=1` et utiliser `$(pwd -W)` | — |
| `dama/doctrine-test-bundle` installé mais non activé (bundle et extension PHPUnit absents) | Sa recette Flex est « contrib », bloquée par défaut (`allow-contrib: false`) | `composer config extra.symfony.allow-contrib true` puis `composer recipes:install dama/doctrine-test-bundle --force` | — |
| « Cannot autowire … has #[Target('command.bus')] but no such target exists » | Le bus par défaut de Messenger n'a pas d'alias nommé | Désigner le bus par son identifiant : `#[Autowire(service: 'command.bus')]` | ADR 0003 |
| `doctrine:migrations:diff` propose `DROP INDEX appointment_no_overlap` | DBAL lit l'index de la contrainte d'exclusion GiST comme un index partiel inconnu du mapping | Index déclaré « en reflet » dans `Appointment.Appointment.orm.xml` ; `doctrine:schema:validate` en CI | ADR 0003 |
| Service introuvable dans un test (« has been removed or inlined ») | Un service privé que rien n'utilise encore est retiré du conteneur compilé | Le déclarer public sous `when@test` dans `config/services.yaml` | — |
| CI : `bin/console: Permission denied` (code 126) | Fichier commité depuis Windows (`core.filemode=false`) : le bit d'exécution est perdu | `git update-index --chmod=+x backend/bin/console` ; vérifier avec `git ls-files -s` (mode `100755`) | commit `2026-11-15 # 10` |
| `git status` liste des fichiers `M` alors que `git diff` est vide | Cache de l'index périmé après le passage des fins de ligne en LF (`.gitattributes`) | `git add -u` (aucun contenu modifié, l'index est seulement rafraîchi) | — |
| `#[MapRequestPayload]` : un tableau d'objets arrive en tableaux bruts (TypeError) | Le Serializer ne lit les types `list<Objet>` des PHPDoc qu'avec `phpstan/phpdoc-parser` **et** `phpdocumentor/type-resolver` | `composer require phpstan/phpdoc-parser phpdocumentor/type-resolver` | — |
